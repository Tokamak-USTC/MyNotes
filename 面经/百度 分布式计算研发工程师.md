7. open一个文件，发生了什么？-> 路径解析（提了一嘴dcache），找到dentry，（通过 **inode number**)找到inode，回填 struct file，把fd返回用户
	- **dcache** 维护的是 **父目录inode + 文件名** -> **struct dentry** 的映射，
	- 路径解析时，访问 dacache **未命中时创建** dentry，dentry 需要持有指向 **struct inode** 的指针（如果当前目录层级下这个文件名不存在，则dentry指向 **NULL** ）
	- dentry 创建时看父目录内容里对应项，拿到对应的 **inode 号**，然后查询 inode cache，命中则直接返回，未命中则根据 inode 号读磁盘并创建
8. 那写入一行呢？-> struct file 里面维护本次写入的偏移，根据这个偏移在inode -> i_mapping里找到对应位置的page cache，把内容写到page cache里面，如果page cache不在内存中，则分配并把对应数据从块设备中读到page cache里面，然后再写
