## 继承时对象的内存布局

```cpp
// 类定义
class A { int a; };  // 4 bytes
class B { int b; };  // 4 bytes
class Derived : public A, public B { int c; };  // 4 bytes

//  对象布局（sizeof(Derived) = 12 bytes）
//
//  地址（低 → 高）    内容               说明
//  ┌───────────────────────────────────────────┐
//  │ 0x00        │  A::a            │ A子对象   │
//  │             │  (offset = 0)    │          │
//  ├─────────────┼──────────────────┤          │
//  │ 0x04        │  B::b            │ B子对象   │
//  │             │  (offset = 4)    │          │
//  ├─────────────┼──────────────────┤          │
//  │ 0x08        │  Derived::c      │ 派生类    │
//  │             │  (offset = 8)    │          │
//  └─────────────┴──────────────────┴──────────┘
//
//  指针值：
//  (A*)&d      → 0x00  (等于 &d)
//  (B*)&d      → 0x04  (等于 &d + 4)
//   &d         → 0x00
//   &d.c       → 0x08

// 调用 this 指针
Derived d;
d.A::func();  // this = 0x00 (A子对象起始)
d.B::func();  // this = 0x04 (B子对象起始)
d.func();     // this = 0x00 (Derived起始)
```

派生类调用**基类方法**时传入的 `this` 指针，指向的是**该基类子对象在派生类对象中的起始位置**；若该基类不是第一个基类，则 `this` 数值会**大于整个对象的起始地址**，偏移量为前面所有基类子对象的大小之和。

## 继承时基类方法的处理/调用机制

基类方法**不会被复制进派生类**，调用时只是将**派生类对象中对应基类子对象的起始地址**（偏移量）作为 `this` 指针传入，从而**复用同一份基类代码**。

## static_cast向下转型

`static_cast<Derived *>(Base *p)` 的时候会自动应用 **Base 在 Derived 中的偏移量**，最后得到指向 Derived 的指针。

```cpp
#include <iostream>
class Base1 {
  int a;
};

class Base2 {
  int b;
};

class Derived : public Base1, public Base2 {
  int c;
};

int main() {
  Base2 b1;
  Base2 *bp = &b1;
  Derived *dp = static_cast<Derived *>(bp); // 根据 bp 类型在 Derived 中的偏移量反推出如果 bp 是一个在 Dervied 中的 Base2, 那么这个 Derived 的地址是什么
  std::cout << "bp: " << bp << std::endl; // bp: 0x16dabef08
  std::cout << "dp: " << dp << std::endl; // dp: 0x16dabef04
}
```
