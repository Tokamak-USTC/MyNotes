## 速览

- `std::sort`、`set`、`map` 的比较器语义一致：`comp(a, b) == true` 表示 `a` 应排在 `b` 前面
- 比较器和 `operator<` 只要被当作排序规则使用，就应满足**严格弱序**，相等或等价时，应满足 `!comp(a, b) && !comp(b, a)`，因此通常返回 `false`
- 很多标准库组件默认使用 `std::less<T>`；自定义类型若想直接吃默认比较器，通常要实现 `operator<`
- `set/map` 判断 key 是否重复，不看 `==`，而看 `!comp(a, b) && !comp(b, a)`
- `priority_queue` 默认也是 `std::less<T>`，但效果是大顶堆，`top()` 是当前最大元素
- `lower_bound(k)` 在默认升序下是第一个 `>= k` 的位置，`upper_bound(k)` 是第一个 `> k` 的位置

## 可比较类型

在 C++ 标准库语境里，“可比较类型”通常指：该类型的对象之间可以按照某种规则比较先后顺序。

这种比较规则可能来自：

- 类型自身实现的 `operator<`
- 标准库提供的默认比较器，例如 `std::less<T>`、`std::greater<T>`
- 用户显式传入的**自定义比较器**

例如，内置类型 `int`、`double`、`char` 天然可比较：

```cpp
1 < 2
3 > 1
```

一些常见标准类型也自带默认比较规则：

- `std::pair<T1, T2>`：先比较 `first`，只有 `first` 相等时才比较 `second`
- `std::tuple<Ts...>`：按成员顺序逐个比较，前面成员分出结果后就停止
- `std::array<T, N>`：按字典序比较
- `std::vector<T>`：按字典序比较
- `std::string`：按字典序比较

其中 `std::array` 和 `std::vector` 的“按字典序比较”可以理解为：

- 先比较第 `0` 个元素
- 如果相等，再比较第 `1` 个元素
- 依次类推
- 如果某一位分出大小，就直接得到整体比较结果
- 如果前面都相等，则较短的序列更小

`std::string` 的字典序比较也遵循同样思路：

- 先比较第 `0` 个字符
- 如果相等，再比较下一个字符
- 如果某一位字符分出大小，就直接得到整体比较结果
- 如果前面所有字符都相等，则较短的字符串更小

这些标准类型能够默认比较的前提是：它们内部元素本身也必须可比较。

而对于自定义类型，如果想让它参与 `std::sort`、`std::set`、`std::map`、`std::priority_queue` 等标准库组件，通常有两种做法：

1. 实现 `operator<`
2. 显式传入比较器

### 默认比较规则

很多标准库组件如果不显式传比较器，默认会使用 `std::less<T>`。

对于大多数类型，`std::less<T>` 通常等价于按 `<` 比较，也就是**小的排前面**。但是，`std::priority_queue`是个例外，**默认小的在后面，大的在前面，也就是堆顶**。

因此，如果一个自定义类型实现了 `operator<`，那么很多场景下就可以直接使用默认比较规则，而不需要额外传比较器。

`std::greater<T>` 使用 `operator>` 。如果显示传 `std::greater<T>` 作为比较器，就要实现`operator>`。

### 自定义类型的可比较方式

示例一：实现 `operator<`

```cpp
struct Item {
  int a;
  int b;

  bool operator<(const Item &other) const {
    if (a != other.a) return a < other.a;
    return b < other.b;
  }
};
```

示例二：显式传入比较器

```cpp
struct Cmp {
  bool operator()(const Item &x, const Item &y) const {
    if (x.a != y.a) return x.a < y.a;
    return x.b < y.b;
  }
};
```

### 比较规则的要求

无论是 `operator<` 还是自定义比较器，只要它要被标准库当作“排序规则”使用，就应满足**严格弱序**（**strict weak ordering**）。

实践上最重要的两点是：

- 不能同时出现 `comp(a, b) == true` 和 `comp(b, a) == true`
- 如果两个元素在当前规则下等价，应满足 `!comp(a, b) && !comp(b, a)`

否则，排序算法和有序容器的行为可能出错。

实践上，如果没有比较出结果的话就返回 **false**

## 排序算法

### std::sort

#### 作用

`std::sort` 用于对一个区间内的元素进行排序。底层使用 `introsort`，内省式排序。

- 平时先用快速排序
- 如果递归过深切换到堆排序
- 小区间用插入排序优化常数

`std::sort` 是**非稳定排序**，平均时间复杂度通常为 `O(n log n)`，最坏时间复杂度也为 `O(n log n)`，因为快排退化时有堆排序兜底。

#### 默认效果

如果不传比较器，则默认按**升序**排序。

- 对内置类型，通常等价于按 `<` 排序
- 对自定义类型，通常要求类型能按默认比较规则比较

#### 参数列表

```cpp
template<class RandomIt>
void sort(RandomIt first, RandomIt last);

template<class RandomIt, class Compare>
void sort(RandomIt first, RandomIt last, Compare comp);
```

含义：

- `first`：排序区间起点迭代器
- `last`：排序区间终点的后一个位置，也是迭代器
- `comp`：比较器，可调用对象。可以是lambda，仿函数，**函数名**，**函数指针**，std::function()等。

比较器语义：

```cpp
comp(a, b) == true
```

表示 `a` 应该排在 `b` **前面**。

因此：

- 升序比较器通常写 `a < b`
- 降序比较器通常写 `a > b`

比较器需要满足**严格弱序**。最重要的实践规则是：

- 不能同时出现 `comp(a, b) == true` 和 `comp(b, a) == true`
- 如果两个元素在当前规则下等价，应返回 **false**

#### 使用例

```cpp
void std_sort() {
  struct Item {
    int a;
    int b;
    int c;
  };

  std::vector<Item> v = {{1, 3, 2}, {2, 3, 1}, {1, 2, 1}, {2, 4, 1}};
  
  std::sort(v.begin(), v.end(), [](const Item &x, const Item &y) {
    if (x.a != y.a) {
      return x.a < y.a;
    }
    if (x.b != y.b) {
      return x.b < y.b;
    }
    if (x.c != y.c) {
      return x.c < y.c;
    }
    return false;
  });
  
  for (const auto &value : v)
    std::cout << value.a << ' ' << value.b << ' ' << value.c << std::endl;
}
```

输出顺序：

```text
1 2 1
1 3 2
2 3 1
2 4 1
```

### std::stable_sort

#### 作用

`std::stable_sort` 用于对一个区间内的元素进行排序，并保证**稳定性**。

稳定性的含义是：如果两个元素在当前排序规则下等价，则排序后它们的相对先后顺序保持不变。

`std::stable_sort` 底层通常使用**归并排序风格的实现**。平均时间复杂度和最坏时间复杂度通常都为 `O(n log n)`。

#### 默认效果

如果不传比较器，则默认按**升序**排序。

- 对内置类型，通常等价于按 `<` 排序
- 对自定义类型，通常要求类型能按默认比较规则比较

#### 参数列表

```cpp
template<class RandomIt>
void stable_sort(RandomIt first, RandomIt last);

template<class RandomIt, class Compare>
void stable_sort(RandomIt first, RandomIt last, Compare comp);
```

含义：

- `first`：排序区间起点迭代器一般可以用
- `last`：排序区间终点的后一个位置，也是迭代器
- `comp`：比较器，可调用对象

比较器语义和 `std::sort` 完全一致：

```cpp
comp(a, b) == true
```

表示 `a` 应该排在 `b` **前面**。

因此：

- 升序比较器通常写 `a < b`
- 降序比较器通常写 `a > b`

比较器同样需要满足**严格弱序**。

#### 使用例

```cpp
void std_stable_sort() {
  struct Item {
    int key;
    char tag;
  };

  std::vector<Item> v = {{2, 'a'}, {1, 'b'}, {2, 'c'}, {1, 'd'}};

  std::stable_sort(v.begin(), v.end(), [](const Item &x, const Item &y) {
    return x.key < y.key;
  });

  for (const auto &value : v)
    std::cout << value.key << ' ' << value.tag << std::endl;
}
```

输出顺序：

```text
1 b
1 d
2 a
2 c
```

这里 `key` 相同的元素相对顺序没有变，例如 `1 b` 仍然排在 `1 d` 前面，`2 a` 仍然排在 `2 c` 前面。

### std::nth_element

#### 作用

`std::nth_element` 用于把区间内第 `n` 小的元素放到**正确位置**上。

执行完成后：

- `nth` 位置上的元素就是如果整体排序后本应出现在该位置的元素
- `nth` 前面的元素都**不大于**它
- `nth` 后面的元素都**不小于**它

但注意：`nth` 两侧的元素**不保证各自内部有序**。

`std::nth_element` 平均时间复杂度通常为 `O(n)`。

#### 默认效果

如果不传比较器，则默认按升序语义选择第 `n` 小元素。

- 对内置类型，通常等价于按 `<` 比较
- 对自定义类型，通常要求类型能按默认比较规则比较

#### 参数列表

```cpp
template<class RandomIt>
void nth_element(RandomIt first, RandomIt nth, RandomIt last);

template<class RandomIt, class Compare>
void nth_element(RandomIt first, RandomIt nth, RandomIt last, Compare comp);
```

含义：

- `first`：区间起点迭代器
- `nth`：**目标位置迭代器**，一般可以用 `first + k` 这种形式来传。
- `last`：区间终点的后一个位置
- `comp`：比较器，可调用对象

比较器语义仍然是：

```cpp
comp(a, b) == true
```

表示 `a` 应该排在 `b` **前面**。

#### 使用例

```cpp
void std_nth_element() {
  std::vector<int> v = {7, 2, 9, 1, 5, 3, 8};

  std::nth_element(v.begin(), v.begin() + 3, v.end());

  for (int value : v)
    std::cout << value << ' ';
  std::cout << std::endl;
}
```

可能输出：

```text
2 1 3 5 9 7 8
```

这里下标 `3` 位置上的元素是 `5`，它就是整个序列排序后应出现在该位置的元素。其左边元素都不大于 `5`，右边元素都不小于 `5`，但左右两侧内部不保证有序。

## 有序容器

有序容器指的是会长期按照某套比较规则维护内部顺序的容器，典型包括：

- `std::set`
- `std::multiset`
- `std::map`
- `std::multimap`

其中：

- `set/multiset` 存储元素本身
- `map/multimap` 存储键值对，但比较器只比较 `key`

### 默认比较器

如果不显式传比较器，则默认使用 `std::less<T>`。

因此：

- `std::set<int>` 默认按**从小到大**组织
- `std::map<int, std::string>` 默认按 `key` **从小到大**组织
- 如果 `key` 是自定义类型，通常需要实现 `operator<`，或者显式传入比较器

例如：

```cpp
std::set<int> s;
std::map<int, std::string> mp;
```

分别等价于：

```cpp
std::set<int, std::less<int>> s;
std::map<int, std::string, std::less<int>> mp;
```

### 比较器语义

有序容器的比较器语义和 `std::sort` 一致：

```cpp
comp(a, b) == true
```

表示 `a` 应该排在 `b` **前面**。

因此默认比较器 `std::less<T>` 下：

- 较小的元素排在前面
- `begin()` 指向最小元素

如果使用：

```cpp
std::set<int, std::greater<int>> s;
```

则顺序会变成从大到小，此时 `begin()` 指向最大元素。

### 等价性

对于有序容器，两个 key 是否等价，不看 `==`，而看：

```cpp
!comp(a, b) && !comp(b, a)
```

如果这个条件成立，容器就认为它们在当前排序规则下等价。

因此：

- `set/map` 不允许出现两个等价 key
- `multiset/multimap` 允许出现多个等价 key

### 上下界查找

`lower_bound(k)` 的结果在默认升序比较器下，可理解为：

- 第一个 `>= k` 的位置
- 第一个**不排在** `k` **前面**的位置


`upper_bound(k)` 的结果在默认升序比较器下，可理解为：

- 第一个 `> k` 的位置
- 第一个**排在 `k` 后面**的位置
- 插入** `k` 而**不影响全局顺序**的最后一个位置

`lower_bound` 和 `upper_bound` 的效果如图所示：

![[lower(upper)_bound|800]]

`lower_bound` 和 `upper_bound` 返回的是迭代器，不是值。

如果想取“小于 `k` 的最大元素”，通常写成：

```cpp
auto it = s.lower_bound(k);
if (it != s.begin()) {
  --it;
}
```

这里得到的是最后一个 `< k` 的元素。

注意：

- 如果 `it == s.begin()`，则不能再前移
- 对 `begin()` 做 `--it` 或 `std::prev(it)` 都是未定义行为

## 优先队列

`std::priority_queue` 是容器适配器，用于维护“当前最优先弹出的元素”。

它的底层通常基于堆实现，因此：

- `top()`：查看堆顶元素
- `push()`：插入元素
- `pop()`：弹出堆顶元素

它**不支持**像 `set/map` 那样的**有序遍历**，也**不支持** `lower_bound/upper_bound` 这类**边界查找**。

### 默认效果

如果不显式传比较器，则默认使用 `std::less<T>`：

```cpp
std::priority_queue<int, std::vector<int>> pq;
```

等价于：

```cpp
std::priority_queue<int, std::vector<int>, std::less<int>> pq;
```

但是，对于 `priority_queue` 来说，比较器返回 `true` 的语义是：**第一个参数要排在第一个参数后面**。这个和 `std::sort` ，有序容器等的直觉刚好相反，最大的元素排在最前面（最先出队），默认效果是**大顶堆**，很坑。

例如：

```cpp
std::priority_queue<int, std::vector<int>> pq;
pq.push(3);
pq.push(5);
pq.push(2);

while (!pq.empty()) {
  std::cout << pq.top() << ' ';
  pq.pop();
}
```

输出顺序：

```text
5 3 2
```

### 参数列表

```cpp
template<
  class T,
  class Container = std::vector<T>,
  class Compare = std::less<typename Container::value_type>
> class priority_queue;
```

含义：

- `T`：元素类型
- `Container`：底层容器类型，通常是 `std::vector<T>`
- `Compare`：比较器类型，是一个类型，而不是对象，这点和 `std::sort` 不同。可以使用自定义的比较器类型，或者 `decltype(lambda)` 
  - 注意，比较器类型的 `operator()` 的入参最好是**值拷贝**或**常引用**，即 `bool operator()(T a, T b)` 或 `bool operator()(const T& a, const T&b)`，因为比较器只需要对某两个元素进行**观察**而不是**修改**，就可以比较大小。不过传普通引用也没关系。
  - 优先队列的 `top()` 方法返回的也是**常引用**，一般先接受一份拷贝，然后 `pop()`，最后使用这个值拷贝。

### 比较器语义

这里最容易和 `std::sort` / `set` / `map` 混淆。

对 `priority_queue` 来说，更适合这样理解：

```cpp
comp(a, b) == true
```

表示 `a` 的优先级比 `b` **低**，也就是 `a` 更应该往下沉。

因此：

- 默认 `std::less<T>` 下，较大的元素优先级更高，所以得到大顶堆
- 如果使用 `std::greater<T>`，则会得到小顶堆

例如：

```cpp
std::priority_queue<int, std::vector<int>, std::greater<int>> pq;
```

此时：

- `top()` 返回当前最小元素
- 持续 `pop()` 时，元素会按从小到大出队

### 自定义类型

如果自定义类型没有默认比较规则，或者想按特定规则组织优先级，则需要显式传入比较器。

```cpp
struct Item {
  int a;
  int b;
  int c;
};

struct Cmp {
  bool operator()(const Item &x, const Item &y) const {
    if (x.a != y.a) {
      return y.a < x.a;
    }
    if (x.b != y.b) {
      return y.b < x.b;
    }
    if (x.c != y.c) {
      return y.c < x.c;
    }
    return false;
  }
};

std::priority_queue<Item, std::vector<Item>, Cmp> pq;
pq.push({2, 3, 1});
pq.push({2, 5, 3});
pq.push({1, 3, 1});
pq.push({1, 2, 5});
```

这个比较器的含义是：

- `a` 小的优先级更高
- 如果 `a` 相同，则 `b` 小的优先级更高
- 如果 `b` 也相同，则 `c` 小的优先级更高

持续出队时，顺序为：

```text
1 2 5
1 3 1
2 3 1
2 5 3
```

### lambda 写法

比较器也可以写成 lambda：

```cpp
auto cmp = [](const Item &x, const Item &y) -> bool {
  if (x.a != y.a) return y.a < x.a;
  if (x.b != y.b) return y.b < x.b;
  if (x.c != y.c) return y.c < x.c;
  return false;
};

std::priority_queue<Item, std::vector<Item>, decltype(cmp)> pq(cmp);
```

这里要注意两点：

- 模板参数位置需要的是**比较器类型**，所以要写 `decltype(cmp)`
- 构造 `priority_queue` 对象时，再把 `cmp` 这个比较器对象传进去

### 使用默认比较器比较自定义类型

如果自定义类型已经实现了 `operator<`，则可以不显式传比较器。

```cpp
struct Item {
  int a;
  int b;
  int c;

  bool operator<(const Item &other) const {
    if (a != other.a) return a < other.a;
    if (b != other.b) return b < other.b;
    if (c != other.c) return c < other.c;
    return false;
  }
};

std::priority_queue<Item, std::vector<Item>> pq;
```

这时默认比较器是 `std::less<Item>`，效果是**大顶堆**，也就是会把按 `operator<` 规则看“**最大**”的元素放到 `top()`。
